# Proyectos Exfor S.A.S

Prueba técnica desarrollada para la empresa **Exfor S.A.S**.

## Descripción

Este proyecto consiste en el desarrollo de un **CRUD para la gestión de proyectos ficticios**, donde un usuario con rol de **Super Administrador** puede administrar tanto los proyectos como los usuarios del sistema.

El objetivo principal es demostrar la implementación de operaciones básicas de gestión de datos y relaciones entre entidades.

## Funcionalidades

El sistema permite al **Super Administrador**:

- Crear proyectos
- Crear usuarios
- Asignar usuarios a proyectos
- Eliminar usuarios
- Eliminar proyectos

## Tecnologías utilizadas

- PHP  
- MySQL  
- HTML  
- CSS  
- JavaScript  

## Objetivo de la prueba

Evaluar habilidades relacionadas con:

- Desarrollo de aplicaciones CRUD
- Manejo de bases de datos relacionales
- Organización básica de un proyecto web
